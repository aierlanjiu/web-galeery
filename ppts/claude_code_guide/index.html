第一步 · Install
05 / 12
Step 1

先装工具

官方推荐 Native Install；DeepSeek 集成文档同时给出 npm 安装方式。你只要保证 claude --version 能出版本号。

# macOS / Linux / WSL
curl -fsSL https://claude.ai/install.sh | bash

# 或使用 npm
npm install -g @anthropic-ai/claude-code

# 验证
claude --version
Node.js 18+ · Windows 需 Git for Windows

第二步 · Model
06 / 12
Step 2

接上模型

这组环境变量来自 DeepSeek 官方 Claude Code 集成页；zsh 下建议给带方括号的模型名加引号。

export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<your DeepSeek API Key>
export ANTHROPIC_MODEL='deepseek-v4-pro[1m]'
export ANTHROPIC_DEFAULT_OPUS_MODEL='deepseek-v4-pro[1m]'
export ANTHROPIC_DEFAULT_SONNET_MODEL='deepseek-v4-pro[1m]'
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max

第三步 · Persist
07 / 12
别每次重配

永久配置

把非敏感变量放进 shell 配置；API Key 尽量放系统钥匙串或本机私密文件，永远不要写入项目仓库。

# macOS Keychain 保存一次
security add-generic-password \
  -a "$USER" \
  -s deepseek-api-key \
  -w "粘贴你的 DeepSeek Key"

# ~/.zshrc 中读取
export ANTHROPIC_AUTH_TOKEN="$(security find-generic-password -a "$USER" -s deepseek-api-key -w)"
Verify
/status
进入项目目录运行 claude，用 /status 看模型与配置来源。
Fallback
flash
子任务和轻任务可交给 deepseek-v4-flash，节省时间与费用。
Rule
safe

把 PPT 生产封装起来

安装技能

xuemu-ppt 已上传到 GitHub。Claude Code 用 ~/.claude/skills/；Codex 用 ~/.codex/skills/ 或 skill-installer。

Claude Code
mkdir -p "$HOME/.claude/skills"
git clone https://github.com/aierlanjiu/xuemu-ppt.git \
  "$HOME/.claude/skills/xuemu-ppt"
Codex
python "$HOME/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py" \
  --repo aierlanjiu/xuemu-ppt \
  --path .
触发方式很简单：$xuemu-ppt 帮我做一份某主题的工业风 HTML PPT。如果想做视频版，再要求输出 MP4。
