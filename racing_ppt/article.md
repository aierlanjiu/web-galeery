## 🛠️ 深度硬核拆解

### 1. 为什么选择 Codex 而不是 Midjourney

Midjourney 的中文渲染一直是痛点——中文文字经常出现乱码、幽灵字、镜像文字。Codex 使用的 gpt-image-2 模型在中文文字渲染上有显著优势，适合需要精确中文排版的科普卡片场景。

更重要的是，Codex 不需要详细的版式指令。Midjourney 提示词通常需要 2000-3000 字的精确布局描述（每个 Section 的位置、字号、颜色等），而 Codex 会自动推断版式——你只需要描述视觉氛围和核心内容，模型会自行完成合理的排版。

### 2. 三种风格的差异化设计逻辑

**工业蓝图** 的视觉 DNA 来自氰版晒图工艺（Cyanotype）——19 世纪工程制图的标准输出格式。深蓝底+白线的配色具有天然的"技术档案"气质，适合解构机械结构和技术参数。福特 GT40 的 7.0L V8 发动机在这种风格下，每一根进气歧管都像一张精密图纸上的标注线。

**赛道纪实** 走的是人文纪实摄影路线——暖色钨丝灯、手写便签、拍立得照片、油渍晕染。这种风格的核心卖点是"真实感"：它不像一张电脑制作的图表，更像从赛车工程师口袋里掏出来的赛道笔记。Lauda vs Hunt 的富士雨战在这种风格下，雨水晕染的墨迹本身就是叙事元素。

**极净实验室** 是最反直觉的设计——用无菌、冷静的展陈方式来呈现最疯狂的赛车技术。Lancia Delta S4 的 480 马力双增压发动机被放在亚克力展柜里，像博物馆的标本。这种"冷感"反而放大了 Group B 时代的疯狂——秩序包裹着混沌。

### 3. Codex OAuth 免 Key 方案的技术原理

Codex.app 将 ChatGPT 的 OAuth token 存储在 macOS Keychain 中。Hermes agent 通过 `security` CLI 读取该 token，然后以 Bearer token 的形式调用 `chatgpt.com/backend-api/codex` 端点。这意味着：

- 不需要 OpenAI API Key（零额外成本）
- 使用你的 ChatGPT 订阅配额（Plus/Pro/Team）
- 日配额与你的订阅等级挂钩（Pro ≈ 200张/天）
- Token 自动续期，无需手动刷新

### 4. 提示词工程的核心原则

这套技能的成功率取决于三个关键因素：

**a) 视觉氛围 > 精确指令。** Codex 不是 Midjourney——给它"一张深蓝色晒图纸，透写台冷白底光"比"在左上角 20px 处放置一个白色文本框"有效 10 倍。

**b) 情感温度决定视觉温度。** 工业蓝图是"冷感理性"，赛道纪实是"炙热人文"，极净实验室是"无菌未来"。这三个温度锚点比任何色彩 hex 值都重要。

**c) 一个视觉锚点 > 十段文字描述。** 每张卡片的核心是一个高精度 3D 零部件渲染——GT40 的 V8 发动机、Lauda 的方向盘、Delta S4 的双增压系统。这个锚点决定了整张卡片的视觉重心。
